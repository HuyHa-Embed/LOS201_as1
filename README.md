# ASSIGNMENT-01: How to Write a Device Driver

## Giới thiệu
Bài tập tập trung vào phát triển Device Driver nâng cao trong Linux Kernel, mở rộng kiến thức từ LAB-02 với các giao diện điều khiển và cơ chế quản lý thiết bị.

## Nội dung thực hiện
- Mở rộng Character Device Driver với ioctl interface.
- Xây dựng Miscellaneous Device Driver.
- Quản lý dữ liệu và bộ đếm trong Kernel.
- Giao tiếp giữa Kernel Space và User Space.
- Phân tích kiến trúc và thiết kế Device Driver.

## Công nghệ sử dụng
- C Programming
- Linux Kernel Module
- ioctl
- Character Device
- Misc Device
- procfs
- QEMU (ARMv7)

## Mục tiêu
Nâng cao kỹ năng thiết kế, triển khai và quản lý Linux Device Driver.
